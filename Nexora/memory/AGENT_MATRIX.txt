1. PROJECT MISSION
--------------------------------------------------------------------------------
Nexora is a cross-platform mobile application (Android & iOS) designed to restore
institutional academic integrity. The platform eradicates anonymous question leaks
and hoarding by enforcing an immutable, vouched academic ledger where every note,
slot, and course is strictly tied to an admin-approved student identity.

3. SHARED DATA CONTRACTS & COLLECTIONS
--------------------------------------------------------------------------------
A. users/{uid} (Verified Student Directory)
   - uid: String
   - email: String
   - name: String
   - regNo: String (e.g., "23BDS0084")
   - branch: String
   - year: String
   - phoneNo: String
   - photoUrl: String?
   - role: "superadmin" | "admin" | "student"
   - adminColorHex: String? (Admin border ring and seal color)
   - approvedBy: String (UID of the admin who approved them)
   - approverColorHex: String (Hex code of the approving admin's seal)
   - academic: Map
       * facultyAdvisor: String
       * coreSlot: String
       * nptel: String
       * extraCurricular: String
       * clubs: List<String>
   - courses: List<Map> [code, name, faculty, slot] (Max 7 courses)
   - searchIndices: Map
       * faculties: List<String> (All faculty names lowercased)
       * regNoLower: String
       * nameLower: String

B. pendingUsers/{uid} (Verification Gate)
   - uid: String
   - email: String
   - name: String
   - regNo: String
   - branch: String
   - year: String
   - phoneNo: String
   - submittedAt: ServerTimestamp

C. notes/{noteId} (Public Academic Ledger)
   - id: String
   - title: String?
   - content: String
   - imageUrl: String?
   - postedByUid: String
   - authorName: String
   - authorRegNo: String
   - timestamp: ServerTimestamp
